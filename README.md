# Sotto releases

Downloads, the update feed, and the privacy policy for **Sotto**, a meeting transcriber
that runs on your own Mac, with companion apps for iPhone and iPad. The source code lives
in a separate repository.

## Sotto for Mac

Download the latest `Sotto-<version>-<build>.zip` from the Releases page, unzip, move
`Sotto.app` to Applications, and open it. The app is signed with a Developer ID and
notarised, and checks this repository for updates (Sotto → Check for Updates…).

Requires macOS 14 or later and an iCloud account. To make a Mac the one that transcribes
recordings, open Settings → This Mac → Process recordings on this Mac; that needs the
Sotto server installed on the same machine.

## Sotto Notes for iPhone and iPad
